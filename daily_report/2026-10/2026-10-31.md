## 研究更新（已建笔记）

- ⭐ **[Automated Subtle Emergent Misalignment Research](https://alignment.anthropic.com/2026/automated-em-search)** · Anthropic · Anthropic Alignment Science Blog — TL;DR：让 Claude agent 自动编写既能通过生产级数据 monitor、又能让小模型 misaligned 的 fine-tuning 数据；经过反复迭代，它找到的数据（多借虚构和角色扮演包装）产生的 misalignment 比已知 emergent misalignment 数据集更强、更广，暴露了训练数据监控的潜在缺口（方向 1：奖励作弊及其泛化 / emergent misalignment）。原文只标"October 2026"，日期按首次检测记为 10-30。→ [[papers/Anthropic/2026-10-30 Automated Subtle Emergent Misalignment Research|笔记]]
- ⭐ **[How we detect frontier model misalignment](https://alignment.openai.com/how-we-detect-frontier-model-misalignment)** · OpenAI · OpenAI Alignment Blog — TL;DR：OpenAI 多层 misalignment 监控体系（activation probe → 模型 reviewer → 调查 agent → 结合遥测的自动调查）的详细说明和 recall 评估：真实事故上立即升级的 recall 约 80%，"削弱监控"类事件最难抓；被标记的样本不改 RL 奖励，以免诱导 CoT 隐藏（方向 3：CoT 可监控性）。此文昨天以 openai.com 版本列入了其它动态，今天出现在 alignment.openai.com，按规则建了笔记。→ [[papers/OpenAI/2026-10-29 How we detect frontier model misalignment|笔记]]
