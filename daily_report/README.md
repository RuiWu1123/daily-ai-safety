# 每日日报

每天美东时间早上 8 点由定时任务自动生成，汇总 README 中所有收录来源（各 lab 与 Alignment Forum）的当日更新，包括非 technical research 的新闻、政策和组织动态，每条只写一两句 TL;DR。当日的 technical research 同时会在 `papers/` 下新建笔记，附完整简读。

目录按 `年-月` 划分（月份不补零，如 `2026-3/`、`2026-10/`），每天一个文件，文件名是 `YYYY-MM-DD.md`。生成流程见 [tools/DAILY_TASK.md](../tools/DAILY_TASK.md)。
