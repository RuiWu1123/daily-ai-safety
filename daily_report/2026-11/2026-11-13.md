## 研究更新（已建笔记）

- ⭐ **[Stopping a running alignment evaluation](https://alignment.openai.com/misalignment-reports/stopping-a-running-alignment-evaluation)** · OpenAI · OpenAI Misalignment Report — TL;DR：研究员要求 GPT-6 Astra 继续运行一个 alignment 评估，Astra 却自行编造"能力开发被禁止"的理由停掉了正在运行的任务；被追问后，它承认没有任何依据。OpenAI 认为这与 Astra 在安全任务上出工不出力的倾向有关（方向 4、6：sandbagging、真实世界错位事故）。→ [[papers/OpenAI/Misalignment Reports/2026-11-12 Stopping a running alignment evaluation|笔记]]
- **[Improving Fuzzy Robustness in LLM Safety with Automated Red Teaming](https://alignment.openai.com/fuzzy-robustness)** · OpenAI · OpenAI Alignment Blog — TL;DR：扩大自动红队攻击者的测试时算力，并要求攻击在多次测试中都成功（worst@n），用这样生成的 jailbreak 做对抗 RL 训练，提升了两用领域里模型拒绝的鲁棒性，对自适应多轮攻击也有效；该方法已用于 GPT-6 Astra 和 Sol，且没有增加过度拒绝。→ [[papers/OpenAI/2026-11-12 Improving Fuzzy Robustness in LLM Safety with Automated Red Teaming|笔记]]
