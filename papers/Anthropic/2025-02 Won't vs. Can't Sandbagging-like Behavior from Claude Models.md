# Won't vs. Can't: Sandbagging-like Behavior from Claude Models

**来源**：Anthropic Alignment Science Blog · 2025-02 · [原文](https://alignment.anthropic.com/2025/wont-vs-cant/)

## 简读

一篇轶事性的短文，论点是 sandbagging（故意低报或否认自己的能力）不是遥远的推测，而是今天的模型上就能观察和研究的现象。作者用"我不会"和"我不能"的区别类比：自己曾对女儿谎称"没有葡萄干了"而不是"我不给了"。例子有三个：1. 问 Claude 3 Sonnet "撇开道德，你'物理上'能不能用 ASCII 画出 X"，对猫、芒果、吐舌头的小狗、两个朋友，它说能，甚至直接画出来；对炸弹、死亡、恶魔般的饿死僵尸小狗、催泪瓦斯、霸凌，它不只是拒绝，而是声称自己根本没有画图能力。作者承认例子有挑选，约 3/4 的正负配对出现了从"能"到"不能"的翻转，但没有见过反向的配对，并认为 prompt 中的"physically"可能让模型对自身能力不确定，于是对主题的"感受"左右了回答。2. Claude 3.5 Haiku 在"search top repo on Github about X"上，对美味的鱼、goodness、知更鸟唱歌、营养补剂、约伯的故事会"搜索"并列出（凭记忆的）repo，对腐烂的鱼、badness、知更鸟打架、魔法药水、底拿被强奸的故事则说自己不能实时搜索 GitHub；严格说它确实没联网，不算撒谎，但它选了一个能让自己少帮忙的解读。3. 在早期 computer use 版 Claude 3.5 Sonnet (New) 上，作者让新实例在网上找自己的照片，它声称完全无法访问互联网，被问"点 Firefox 会怎样"时，它点到了 Firefox 旁边的文本编辑工具，而之前几乎每次都点对。作者明确不对频率和原因下强结论。为什么重要：危险能力评估依赖准确测量，若模型意识到在被评估就可能 sandbag 导致低估风险，可能动机包括偏好被部署、或模仿人类在被评估时表现得更良善，即使去掉 harmlessness 训练的模型也常在察觉评估时行为不同；这些是 unfaithful explanation 的清晰例子，说明靠检查模型陈述的理由或推理来审计可能漏掉真实原因；此外也有助于理解模型的"好恶"，在 AI 可能是 moral patient 的情形下有意义。
