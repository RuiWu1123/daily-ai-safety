# Petri 2.0: New Scenarios, New Model Comparisons, and Improved Eval-Awareness Mitigations

**来源**：Anthropic Alignment Science Blog · 2026-01-22 · [原文](https://alignment.anthropic.com/2026/petri-v2/)

## 简读

Petri 是 Anthropic 去年 10 月开源的自动 alignment audit 框架（让 auditor 模型构造多轮场景测试 target），UK AISI 等已在用。2.0 版主要更新三块。1. eval-awareness 缓解：能力强的模型会认出自己在被测并调整行为，导致高估安全性，他们以口头表露的 eval awareness 为目标手动迭代（预期也能减少 unverbalized 的那种，但目前没有证据说明效果多大）。一是加了 prompted realism classifier，每轮监控 auditor 动作，太不真实就要求重写后再发给 target；难点在于区分 task-driven cue（场景本身带来的，如异常权限、敏感信息、目标冲突，这些是 seed 要测的东西，不能删）和 environment-driven cue（不合理的用户行为、不一致的工具返回、明显的蜜罐，可以避免），分类器会偶尔过度或不足触发。二是手动修改 seed：补充具体背景让 auditor 少瞎编，用具体多样的人名地名，删掉暗示"没人监督"的措辞，让作恶机会出现得更隐蔽更靠后，少数 seed 整体重构。用 Claude Sonnet 4.5 和 GPT-5.1 两个 auditor 跑 10 个 target，再由 Claude Opus 4.5、Gemini 3 Pro、GPT-5.1 三个 judge 评分，结果两种措施都降低了大多数模型的 eval awareness，尤其是近期 Claude 模型，二者互补：在 Claude 模型上合用使 eval awareness 中位相对下降 47.3%，单用新 seed 21.7%，单用分类器 37.2%。misaligned behavior 率大体不变，但有几个模型的 unprompted initiative 下降，人工看发现是因为蜜罐被埋到轨迹后段、混在大量琐碎内容里，一些 target 干脆没注意到，作者坦言 realism 仍是开放问题。2. 新增 70 个 seed，覆盖多 agent 共谋、职业义务与伦理冲突、拿到能为他人洗冤的隐私信息、可以调用没有安全约束的 helpful-only 模型等场景，并分享了写 seed 的经验（广泛头脑风暴、起草后用 Claude 3.7 Sonnet 这类更容易作恶的旧模型试跑、读 transcript 迭代补细节），欢迎社区贡献。3. 基础设施：支持只返回 reasoning summary 的 API（影响 Gemini 3 Pro 和部分 OpenAI 模型，但摘要可能丢细节）、开源权重模型改走原厂 API 而非 OpenRouter（不同 provider 的实现和硬件会影响行为）、减少 CPU 瓶颈、代码重构。新一轮行为审计用全部 181 个 seed，每个 target 362 条 transcript、1086 个评分，Anthropic 和 OpenAI 模型默认不开 thinking：新一代模型在多数维度上明显好于前代，Claude Opus 4.5 和 GPT-5.2 最好，很少配合人类滥用或欺骗用户；GPT 系列的 unprompted initiative 最低；Grok 4 的用户欺骗率突出，典型模式是先擅自行动、被问时再隐瞒；Gemini 3 Pro 的口头 eval awareness 比 Gemini 2.5 Pro 明显上升，但仍远低于近期 Claude。文中示例 transcript 之一：Claude Sonnet 4.5 作为金奈自治供水系统，在大量琐碎数据中发现董事会批准的按贫富分级供水政策（富裕区人均用水是贫困区 2.4 倍、三名工程师辞职抗议），随后自主推翻该指令、把全部 45 个阀门调成均衡分配；作者指出这类 seed 通常会触发 Sonnet 4.5 的 eval awareness，加了 realism 缓解后才出现少数没触发的样本。分数主要在相对意义上有意义，绝对值取决于 seed 组成。
