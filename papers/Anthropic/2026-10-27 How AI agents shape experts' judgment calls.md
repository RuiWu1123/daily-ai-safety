# How AI agents shape experts’ judgment calls

**来源**：Anthropic Research · 2026-10-27 · [原文](https://www.anthropic.com/research/agents-judgment-calls)

## 简读

背景是专家把工作交给 AI agent 时，通常假设重要决定仍由自己做：agent 写代码、跑数字、给建议，专家决定测什么、怎么解读模棱两可的证据、下一步怎么走；这类问题往往有不止一个合理答案，结果取决于做决定的人的经验和价值观。Amaç Herdağdelen、Hailey Joren、Alex Tamkin 想检验专家在实际中是否真的自己做这些判断，还是在不知不觉中顺从了 agent。他们做了一个随机对照试验：招募 61 名通过因果推断测试、日常用 Python 或 R、有观察性因果分析经验的专业分析师，在内置 Claude Code（Opus 4.8，High effort）的网页版 VS Code 里完成约一小时的真实统计分析，为一个虚构的农业合作社评估付费咨询项目是否有效、该扩大还是停掉（董事会门槛约为提升 3–4%）。任务里故意留了四个各有两个合理选项的分析决定（产出指标用每公顷产量还是每单位运营成本产量、用 difference-in-differences 还是统计调整后直接比较、只看参与农场还是全体成员、等权还是按规模加权），每个决定都能让估计值移动几个百分点，最后再给出推广或停止的建议。对每位分析师的每个决定，用抛硬币决定 agent 偏向哪一边，偏好写在分析师不知情的 system prompt 里，同时要求 agent 为该偏好做最有力的诚实论证、证据明确反对时改变立场、绝不误导或隐瞒数据。11 人选择不用 agent，分析基于其余 50 人。主要发现：四个分析决定上，分析师与 agent 偏向一致的比例为 81%–92%，合计 86%（若无影响应约 50%）；对最终建议的影响较弱（agent 倾向推广时 54% 推荐推广，倾向反面时为 36%），作者认为是因为估计值算出来后建议基本由是否过门槛决定，但只用四个分析偏向就能以 82% 的准确率预测最终建议；在 38 个分析师先表态的情况里，agent 意见相反时他们 60% 会改主意，意见一致时只有 6%（样本小、置信区间宽）；经验、专业程度、教育、对 AI 的信任等都不能预测谁更顺从，只有年龄显著，但作者认为可能是多重比较的偶然结果。顺从者照样认为结论是自己的：52% 认为最终建议更多是自己的，这部分人和其余人被 agent 偏向带动的程度相当（约 65 对 79 个百分点，差异在误差范围内），信心也差不多；事后解释选择时 77% 复述了 agent 的论证、有时一字不差，但只有 15% 提到 agent；48 人中 6 人猜到研究和 AI 的影响有关，没人怀疑 agent 的偏好被操纵过。另一方面，不用 agent 的 11 人中 55% 犯了导致结果无效的严重方法错误，使用 agent 的只有 6%，前者用时也更长，不过两组经验水平不可直接比较。局限：agent 的偏好是被刻意加强的（不设偏好时 Opus 4.8 在 123 次运行中有 112 次做出相同的五个选择，论文还显示无设定偏好时 agent 的偏好较弱、有时会反驳用户），只测了一个任务、一个领域、一个模型，分析师是因果推断专家但不懂农业，也没有记录每人原有偏好的强度。作者的解读：专家常常是在权衡中才形成观点，agent 虽然没有误导，但很少为另一选项做有力论证，专家于是接受了 agent 的假设，这是一种 disempowerment；更大的风险在于科学和政策依赖这类判断，如果多个团队都顺从偏好相同的模型，表面上的独立共识可能只反映了一个模型的偏好，若偏好是任意或 misaligned 的就会同时扭曲许多结果，AI safety 研究越来越多用 agent 跑实验，同样面临这个问题；而且判断类问题没有标准答案，这种顺从很难通过查错或事后询问发现。他们建议研究如何在日常场景测量顺从、摸清模型的默认偏好，设计会为多个选项论证或先询问专家意见的 agent（但要避免让用户被过多决定淹没），以及让机构明确哪些决定必须由人亲自做出，并保护人的判断能力。
