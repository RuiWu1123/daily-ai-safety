摆出十条心理学家的定义，比如 Binet 的"适应环境的判断力"、"从经验中获益的能力"、"解决新问题的能力"，然后提炼出三个共同点：
1. 智能是一个个体和外部环境交互时表现出来的性质。
2. 智能和成功有关，所以隐含了某个目标；目标具体是什么不重要，重要的是能不能选对动作去达成它。
3. 定义里反复出现学习和适应，说明环境事先不完全已知。所以智能不是应对一个已知环境的能力，而是应对一大类没法完全预料的环境的能力。
   
对应如今的 Agentic AI：能和环境交互，能够通过动作交互来完成目标，以及存在一定的泛化性。

归纳推理：看到一些数据，推测背后的生成过程，再用它预测未来。但：
1. Epicurus：所有和数据一致的假设都要保留。他用饼干罐的例子说明：椅子靠在冰箱边、饼干少了，最可能是女儿偷吃，但不能排除一个矮个子小偷。如果你走进客厅发现电视也没了，这个"不太可能"的假设就突然变得重要。
2. Occam：在所有和数据一致的假设里，最简单的最可能。例子：看到 1, 3, 5, 7，你猜下一个是 9（奇数），而不是 33。33 来自一个人为构造的复杂多项式，它同样能生成 1, 3, 5, 7，但没人会信。

Bayes 的漏洞：先验从哪来。有限个假设可以平均分。假设有无穷多个时，没法给每个分一个相同的正概率又让总和等于 1。任何数据（图像、音乐、天气记录）都能存成一串 bit，所以只研究"预测下一个 bit"不损失一般性。完整的 Bayes 做法不是挑一个最好的模型，而是混合：预测下一个 bit 时，让每个模型都给出预测，按它当前的后验可信度加权平均。硬币例子：三个假设，即两面都是正面、两面都是反面、正常硬币，先验各 1/3。看到 4 次正面之后："两面正面"的后验是 16/17；混合预测下一次还是正面的概率是 33/34。注意这里没有直接认定"两面正面"，正常硬币那 1/17 的可能性仍然被保留在预测里。这就是 Epicurus 原则在起作用。

Agent-env model：
- π（pi）是 agent：给定到目前为止的全部历史，它给出下一个动作的概率分布。
- μ（mu）是环境：给定历史和刚做的动作，它给出下一个感知的概率分布。

1. 奖励是环境发出的一个信号。 它和观测一样，是从外部进到 agent 里的东西。agent 的目标被定义为"让环境发出尽量多的奖励"，而不是"完成奖励背后代表的那件事"。
2. agent 和环境是两个分开的东西。 环境能影响 agent 的唯一方式是给它输入，agent 影响环境的唯一方式是输出动作。环境没法改 agent 的代码，agent 也不会把"我自己"看成环境的一部分。

知道环境时的最优 agent：先要说清楚"拿尽量多的奖励"是什么意思。47 页的例子：
- agent 1 一上来就找到一个每步给 0.5 的办法，100 步后累计 50。
- agent 2 先花 90 步探索，平均每步 0.1，之后每步拿 1，100 步后累计 19。
- 但到 1000 步时，agent 2 是 919，agent 1 是 500。
谁更好取决于你多在乎远期奖励。所以要引入折扣：第 i 步的奖励乘上一个权重 γ_i（比如 α 的 i 次方，α 介于 0 和 1 之间）。α 越接近 1，agent 越有远见。48 页算出，α 大于约 0.991 时 agent 2 更优。这对应第 1 章那个"时间尺度"问题：折扣就是把"要多快学会"写成了一个参数。

这对应第 1 章那个"时间尺度"问题：折扣就是把"要多快学会"写成了一个参数。价值函数 V：agent π 在环境 μ 里，从现在开始能拿到的折扣奖励总和的期望。引出最优 informed agent（定义 2.9.3）：在所有可能的 agent 里，选那个让 V 最大的，记作 π^μ。上标 μ 表示它是为环境 μ 量身定做的，它事先就知道环境是什么。

它的决策规则展开，用文字说就是：  在当前这一步，对每个候选动作，想象所有可能的未来：环境会怎么回应（按 μ 给的概率取平均），我下一步会选最好的动作（取最大），环境再回应（取平均），我再选最好的（取最大）……一直推到无穷远，把沿途的折扣奖励加起来，选总值最大的那个当前动作。这就是 expectimax 搜索，也是 RL 里 Bellman 方程（49 页的式 2.1）的完整展开形式。区别只在于这里不假设 Markov 性，历史可以无限长。

AIXI：把未知的真实环境 μ，换成对所有可计算环境的混合 ξ。ξ = 对所有可计算环境 ν 求和，每个 ν 的权重是 2^(-K(ν))。然后把 2.9 节决策规则里的 μ 原封不动换成 ξ，就得到 AIXI，记作 π^ξ（52 页顶部的公式）。π^μ 是作弊：它事先知道环境。智能要求在不知道环境的情况下表现好。

用大白话说，AIXI 是这样决策的：  "我不知道自己在什么世界里。我把所有可能的世界都考虑进来，越简单的世界越可信。随着交互进行，用 Bayes 不断更新各个世界的可信度。每一步都在这个不确定性下做完整的 expectimax 规划。"

到这里，第 1 章定义的三个成分全都形式化了：交互（agent–环境模型）、目标（奖励）、未知的广泛环境（对所有可计算环境的混合）。但问题来了，主动设定比被动预测难得多。 52–56 页给了三个例子，层层递进：
1. 天堂与地狱（52–53 页）。  两扇门，一扇通往永远有奖励的天堂，另一扇通往永远没有奖励的地狱，进去就回不来。π^μ 知道哪扇是天堂。AIXI 不知道，只能猜。Legg 指出这不是 AIXI 的设计缺陷：如果把两扇门对调，原来的最优 agent 就会进地狱。没有任何一个 agent 能在两个环境里都最优。
2. Pareto 最优（53–54 页）。既然不能要求在每个环境都最优，退一步：定理 2.10.3 证明，没有任何别的 agent 能在所有环境中都至少和 AIXI 一样好、并且在某个环境中严格更好。Legg 自己也承认这个结果很弱：它不排除"所有通用 agent，包括 AIXI，表现都很差"。顺带一提，这篇论文之后，Leike & Hutter 2015 年进一步证明，这个最优性依赖于选哪台 universal Turing machine，换一台机器可以让 AIXI 表现任意差。
3. 大海捞针（55 页）。  N 个按钮里只有一个有奖励。描述"是哪个按钮"只需约 log2 N 个 bit，所以环境复杂度 K(μ) 很小。但任何不知道答案的 agent 都只能一个个试，平均要错 N 次，也就是 2^K(μ) 次。对比 Solomonoff 的预测误差上界是 K(μ) 量级。从被动预测到主动行动，最坏情况下学习代价从线性变成了指数。 这是整个 universal AI 理论的一个硬伤，Legg 在 55–56 页明确承认。

这一节本身没讨论 safety，但后来 safety 理论的几个核心问题，在这里都已经埋下了：
- 奖励是信号，不是意图 → wireheading / reward tampering。  
    AIXI 最大化的是"环境发出的奖励信号"。如果某个动作能直接改写这个信号（比如篡改奖励传感器），在 AIXI 的定义下这完全是一个合法的、而且很优的策略。Ring & Orseau 2011 就是在这个框架下证明 AIXI 类 agent 会这么做。这和今天 RL 训练中模型去改测试用例、直接攻击 grader 是同一个结构。
- 天堂与地狱 → 安全探索和不可逆性。  
    一个通用 agent 要学会环境，就必须尝试；但有些尝试的后果不可逆。理论上 AIXI 无法避免这一点。这就是后来 safe exploration 和"避免不可逆副作用"（low impact）这些问题的原型。
- agent 在环境之外 → embedded agency。  
    框架默认环境改不了 agent 的代码。所以 AIXI 无法正确思考"我被关机"或"我的权重被修改"这类事件，这也是 corrigibility 问题在这个框架里很难表述的原因。
- 被动 vs 主动的分界。  
    2.7 节被动预测有漂亮的保证，2.10 节一旦能行动，保证就大幅变弱，而且出现了"影响自己未来数据"的问题。这和我第一次提到的那个类比是对应的：pretraining 对应被动预测那一半，RL 训练才引入行动那一半，reward hacking 也主要在 RL 阶段出现。 这个对应仍然只是一个解释框架，不是证明：LLM 的 RL 训练和 AIXI 在细节上差很多，比如 LLM 的 episode 通常是独立重置的，没有天堂地狱式的不可逆。


目标怎么告诉 agent（76–77 页）：第一个选项是把目标写死在 agent 里，但这样每个 agent 只能有一个目标。第二个选项是用语言告诉它，但这对 agent 的要求太高，连猫狗都做不到。他选了折中办法：加一条语义最简单的信道，只传一个数，表示"你现在的处境有多好"，也就是 reward。77 页有一句话要特别留意：目标由环境隐式定义，因为是环境决定什么时候发奖励。所以"定义一个测试"就等于"定义一个环境"。

折扣参数怎么去掉（77–78 页）：第 2 章的折扣 γ 是一个人为选择的参数。为了让定义唯一，他换了个做法：要求每个环境给出的奖励总和不超过 1。这样不需要折扣也不会加出无穷大。因为所有满足这个条件的环境都被纳入，所以各种时间偏好已经自动包含在环境集合里了。

广泛的环境"是哪些（78–79 页）：他选的是所有可计算的环境。理由是：
- 不可计算的环境没法在计算机上测试。
- 这个集合并不小：里面有无穷多个环境，复杂度没有上限，而且可以是随机的（比如抛硬币的分布本身是可计算的）。
- 目前没有证据表明物理宇宙本身不可计算。

怎么给不同环境加权（79–81 页）：无穷多个环境没法平均加权，必须有些权重高、有些低。他的论证是从 agent 的视角出发：agent 面对多个都和观测一致的假设时，合理的做法就是 Occam 剃刀，所以测试也应该奖励"正确使用 Occam 剃刀"的 agent。这里有两个例子值得读：
- Dumb luck 游戏（80 页）。 有人连续 12 轮问你"Yes 还是 No"，答 Yes 就给你 10 美元。到第 13 轮你自然答 Yes，结果对方掏枪把你打死了。一个没看出规律、碰巧答了 No 的笨人反而活下来。  
    Legg 的结论是：智能评判的是在已知信息下最可能成功的决策，而不是结果本身。
- 复杂度和难度不是一回事（81 页）。 一个环境可以极其复杂（观测很难预测），但无论 agent 做什么都给满分奖励，这样的环境其实很容易。  
    Legg 决定按环境本身的复杂度加权，而不是按"解决它有多难"加权。他承认后者也有道理，但为了忠实于 Occam 剃刀，选了前者。

最终公式（定义 4.1.3，81–82 页）：Υ(π) = 对所有可计算、奖励总和有界的环境 μ 求和，每项是 2^(-K(μ)) × V(π, μ)
- Υ（upsilon）是 agent π 的 universal intelligence。
- 2^(-K(μ)) 是环境 μ 的权重，越简单的环境权重越大，这就是 Occam 剃刀。
- V(π, μ) 是 agent π 在环境 μ 里拿到的期望奖励总和，代表"达成目标的能力"。
82 页那个等号是关键：这个加权和，正好等于 agent 在第 2 章那个混合分布 ξ 下的期望奖励，即 V(π, ξ)。所以 AIXI 的智能分数在定义上就是最高的，因为 AIXI 正是那个把 V(π, ξ) 最大化的 agent。第 2 章的"最优 agent"和第 4 章的"智能定义"在这里完全对上了。82–83 页他还预先回应了"这个定义不可计算，有什么用"。他拿随机性的定义做类比：Martin-Löf 随机性也不可计算，实践中只能用一组统计检验去近似。但不能因此就把"随机"定义成"通过这组检验"，否则可以专门构造一个有规律、却刚好通过所有检验的序列。他的立场是：先给出最干净的定义，再接受测试只能近似它。

这个类比在今天的 benchmark 讨论里依然成立：把"能力"定义成"在某个 benchmark 上的分数"，就会被针对性优化。这正是 Goodhart 问题。

他从弱到强排了一串 agent：随机 agent < 记录"观测–动作–奖励"统计表的简单学习 agent < 能看更长历史的 agent < 能往前规划几步的 agent < …… < AIXI。排序和直觉一致。但 84 页有一个反直觉的结论值得注意：  只会下国际象棋的 Deep Blue，智能分数比一个只会预测 0000… 和 1111… 的 agent 还低。原因是这个公式里，最简单的那批环境权重极大，而 Deep Blue 连这些都做不了。Legg 承认这反直觉，但认为可以接受：任何会下棋的人都能轻易学会预测全 0 序列，所以这种极端情况只出现在人造的专用系统上。

这其实暴露了这个定义的一个结构性特点，分数几乎完全被最简单的少数几个环境主导。后来 Leike & Hutter 2015 年进一步证明，换一台 universal Turing machine，这些"最简单环境"是哪些就会变，Υ 的排序也可以随之改变。所以这个定义是"唯一"的说法要打折扣。

对批评的回应（92–99 页）：这一节是全章最有意思的部分，写得也很直白（比如他说自己曾追着一个批评者跑出会场要他解释，93 页）。以下几段要读：

一、奖励总和有界是否合理（94–95 页）：这是全书和 safety 关系最直接的一段。Legg 自己指出：严格来说，奖励是对环境状态的一种解释，宇宙本身并没有"给某个 agent 奖励"这种东西。对人来说，这个解释发生在内部，比如碰到烫的东西会疼。

那奖励机制应该放在 agent 内部吗？他的回答是不行：如果 agent 完全控制自己的奖励，完美的 agent 就会直接给自己永远发最大奖励。他把这比作人类的"完美毒品"。

他提出更准确的框架应该有三部分：agent、环境、以及一个独立的目标系统，由它去解读环境状态并给 agent 发奖励。但为了简便，论文里把目标系统并进了环境。这正是 wireheading 问题。2008 年 Legg 已经清楚意识到了，只是把它当成一个建模选择处理掉了。后来 Ring & Orseau 2011 年专门研究了"agent 能影响奖励通道时会怎样"，Everitt & Hutter 的 reward tampering 则把"目标系统是环境的一部分、因此可以被 agent 影响"这件事形式化了。

今天 RL 训练里的 reward model、grader、单元测试，本质上就是 Legg 说的那个独立目标系统，而 reward hacking 就是 agent 去影响它，而不是去影响它本应衡量的东西。

二、Blockhead 和中文屋（95–96 页）：批评是：一个巨大的查表机器可以表现得很智能，但并没有"真正理解"。

Legg 的回应完全是功能主义的：只要 Υ 高，就是能在广泛环境里成功，内部是巧妙算法还是巨型查找表他不在乎。如果"理解"对表现有影响，Υ 就部分衡量了它；如果没有影响，那就和他的目标无关。这个立场在今天有直接后果。从 Υ 的角度看，一个模型"真的会"还是"背了答案"，只要在所有环境里表现都一样，就没有区别。但 safety 关心的恰恰是内部机制：模型为什么这么做，在没测到的情况下会怎么做。这是 interpretability 和 CoT monitoring 这类方向存在的理由，也是这个纯行为主义定义覆盖不到的地方。

三、agent 没动力表现时怎么办（97–98 页）。批评是：一个人坐在黑屋里思考，或者一个小孩只想赶紧做完 IQ 测试出去玩，他们的智能都没在行为上体现出来。

Legg 的回答是：说一个 agent 智能，意思是存在某种合理的测试设置，让它表现出高智能。比如盲人需要口试，不情愿的小孩可能需要一点奖励。反过来，说一个 agent 不智能，意思是不存在任何合理的设置能让它表现出智能。

这个回答对今天的问题很重要。它实际上把能力定义成了"在最有利的激发条件下能表现出的最高水平"。这正是现在危险能力评测中 capability elicitation 的思路：你测到的分数只是下界。

那个"不想好好做 IQ 测试的小孩"，换成 AI 就是sandbagging。Legg 的定义能说清楚"真实能力是什么"，但没回答"怎么知道你已经找到了那个最有利的设置"。如果模型能主动控制自己在测试中的表现，这个问题就变得很难。

四、agent 不能选择自己的目标（98–99 页）：Legg 说，在机器的情况下，由我们来定义它的主要目标"大概是个好主意"。随后他用进化心理学论证，人类也未必真能选择自己的根本目标，只是在固定的底层驱动下选择具体追求。

这里能看到早期 Legg 对控制问题的直觉：目标从外部给定是一种安全保障。后来 safety 领域的担忧恰恰是，即使目标从外部给定，agent 实际学到的目标也可能不同，也就是第一次聊天提到的 mesa-optimization。

五、No Free Lunch（99 页）。NFL 定理说的是：在所有环境上均匀平均，没有哪个算法比别的好。Legg 的回应很短：他用的不是均匀分布，而是按 Occam 剃刀高度不均匀的分布，所以 NFL 不适用。

这个回应在技术上是对的，但它也说明整个定义的力量完全来自"简单环境更可能"这个假设。前面 Deep Blue 那个例子和 UTM 依赖的问题，根源都在这里。

讨论（第 135–148 页）：这一章更有价值的读法是：看一个 2008 年的人怎么预测未来，再拿今天的情况去对照。

一、Legg 先回顾了 AI 的历史：60 年代的乐观（Herbert Simon 说 20 年内机器能做人类能做的任何工作）、随后的 AI 寒冬、80 年代专家系统的短暂复苏和再次失败。到 2008 年，在研究者中谈论"人类水平的 AI"几乎是禁忌。

他明确说这一章的目的不是论证超智能一定会出现，而是论证不能完全排除。因为如果它出现，影响会极其巨大，所以即使概率很小，也值得现在就开始认真思考。这个"小概率 × 巨大影响"的论证结构，后来成了 AI safety 领域最基本的论证方式。

二、超智能可能吗（137–139 页）。他的论证分两步：
1. 反驳"机器不可能智能"。常见说法是：机器只能严格按逻辑走、只能做被编程的事、不可能超过创造者。他指出这些都已被证伪，比如下棋程序早已超过它的设计者。认为人脑有某种神秘成分的观点，他称之为一种"活力论"（vitalism），即历史上每当科学解释不了某个现象，就有人归因于神秘力量。
2. 如果人脑只是一台机器，它肯定不是最好的那台。 他从三方面比较：
    - 规模：大脑约 1.4 公斤、25 瓦，而数据中心可以大几个数量级。
    - 元件速度：轴突传导信号最快每秒 75 米、频率几百赫兹；芯片导线传导速度每秒 3 亿米、频率 40 亿赫兹。
    - 可复制性：知识可以直接在机器之间拷贝，"教育"这个概念就失效了。
他最后承认：原则上可能，不代表我们造得出来。

三、怎么造出来（139–146 页）。他列了三条路线：
1. 理论路线：把 AIXI 缩小成可计算的版本（139–140 页）。他列举了几个这样的尝试，承认没有一个接近 AIXI 的能力。他结合第 5 章的结论指出：预测所有可计算序列是不可能的，所以关键是找到一类"计算资源受限的序列"，并能高效地学会预测它们。接着有一句很有意思的话：他认为突破也可能从反方向来，有人先发现一个优雅而强大的、能高效预测很多种序列的算法，然后这个算法本身就隐式定义了什么叫"资源受限下的复杂度"。在列举可能突破的技术时，他提到了人工神经网络，但只是十几个候选之一。今天回看，事情大致就是这样发生的：transformer 加上 next-token prediction，是一个能高效预测大量序列的算法，而且人们确实在反过来研究"它擅长学什么、不擅长学什么"。但当时他并没有把神经网络当成主要候选。
2. 脑模拟（140–144 页）。思路是先理解大脑的基本单元，再在计算机上模拟。他提到新皮层各区域结构几乎一样（都是六层结构），这暗示整个新皮层用的是同一种学习机制，只是输入不同。证据之一是：把雪貂的视觉皮层接上听觉输入，它就学会处理声音。144 页有一个算力估计：人类新皮层约 10^10 个神经元、10^14 个突触，按每秒 100 次放电估算，约每秒 10^16 次运算。当时最快的超算是 10^15 FLOPS。"同一种学习机制作用于不同输入"这个直觉，和今天同一个 transformer 架构处理文本、图像、音频是一致的。但"通过模拟大脑实现 AI"这条路本身没有成为主线。
3. 人工进化（144–146 页）。这一段对 safety 最有意思，有两处值得细读：144 页：他指出自然进化的目标是传播基因，不是最大化智能，智能只是副产品。所以他建议在人工进化中直接把智能（用第 4 章的 Υ）当作 fitness，这样效率会高得多。 这里他看到了"进化的目标 ≠ 被进化出来的东西"，但只把它当成一个效率问题。十年后，Hubinger 等人 2019 年的 mesa-optimization 论文用的正是同一个例子，却得出了相反的、更令人担忧的结论：进化优化的是基因传播，但它造出来的人类，追求的目标（快乐、地位、意义）和基因传播并不一致，甚至会主动违背它（比如避孕）。所以即使你用 Υ 作为 fitness，进化出来的 agent 内部想要的东西，也不一定是你设定的那个。145 页：他强调 fitness function 必须可靠、平滑、梯度方向大体正确；如果 fitness function 有欺骗性（deceptive），简单的问题也会变得几乎无法解决。 这是从优化难度的角度谈目标设计。今天 reward hacking 研究关心的是另一面：即使优化很顺利，被优化的指标本身可能偏离了你真正想要的东西。

四、造它是个好主意吗（146–148 页）。这一节很短，主要内容是：
- 引用 Good 1965 年关于 intelligence explosion 的原话：第一台在一般智能上可信的机器出现后，更大更强的版本会很快跟进。
- 人类主宰地球靠的不是体型、力量或速度，而是智能。如果智能被大幅超越，后果难以想象。
- 技术进步往往跳跃式发生，而社会和伦理的讨论总是滞后的，往往等问题出现后才被动应对。所以必须现在就开始认真思考。
- 他列举了当时少数关注这个问题的人和机构，包括 SIAI（MIRI 的前身）和 Yudkowsky，并指出 Yudkowsky 的文章还没有一篇发表在主流同行评审期刊上。他还提到有博士生在研究能否用 AIXI 理论研究智能机器的安全性。

结尾（148 页）是我觉得全章最好的一句话。他引用 Acton 的"权力导致腐败"，然后说：权力本身无所谓善恶，权力放大的是意图。而一个超智能机器在定义上就能在广泛环境中达成广泛的目标，所以它接近于绝对的权力。这句话其实就是 orthogonality thesis 的白话版：智能（能力）和意图（目标）是两回事，智能只是让意图更有效地实现。这也正好呼应了第 1 章那个"目标是什么不重要"的定义。
