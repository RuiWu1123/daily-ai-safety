摆出十条心理学家的定义，比如 Binet 的"适应环境的判断力"、"从经验中获益的能力"、"解决新问题的能力"，然后提炼出三个共同点：
1. 智能是一个个体和外部环境交互时表现出来的性质。
2. 智能和成功有关，所以隐含了某个目标；目标具体是什么不重要，重要的是能不能选对动作去达成它。
3. 定义里反复出现学习和适应，说明环境事先不完全已知。所以智能不是应对一个已知环境的能力，而是应对一大类没法完全预料的环境的能力。
   
对应如今的 Agentic AI：能和环境交互，能够通过动作交互来完成目标，以及存在一定的泛化性。

归纳推理：看到一些数据，推测背后的生成过程，再用它预测未来。但：
1. Epicurus：所有和数据一致的假设都要保留。他用饼干罐的例子说明：椅子靠在冰箱边、饼干少了，最可能是女儿偷吃，但不能排除一个矮个子小偷。如果你走进客厅发现电视也没了，这个"不太可能"的假设就突然变得重要。
2. Occam：在所有和数据一致的假设里，最简单的最可能。例子：看到 1, 3, 5, 7，你猜下一个是 9（奇数），而不是 33。33 来自一个人为构造的复杂多项式，它同样能生成 1, 3, 5, 7，但没人会信。

Bayes 的漏洞：先验从哪来。有限个假设可以平均分。假设有无穷多个时，没法给每个分一个相同的正概率又让总和等于 1。任何数据（图像、音乐、天气记录）都能存成一串 bit，所以只研究"预测下一个 bit"不损失一般性。完整的 Bayes 做法不是挑一个最好的模型，而是混合：预测下一个 bit 时，让每个模型都给出预测，按它当前的后验可信度加权平均。硬币例子：三个假设，即两面都是正面、两面都是反面、正常硬币，先验各 1/3。看到 4 次正面之后："两面正面"的后验是 16/17；混合预测下一次还是正面的概率是 33/34。注意这里没有直接认定"两面正面"，正常硬币那 1/17 的可能性仍然被保留在预测里。这就是 Epicurus 原则在起作用。

Agent-env model：
- π（pi）是 agent：给定到目前为止的全部历史，它给出下一个动作的概率分布。
- μ（mu）是环境：给定历史和刚做的动作，它给出下一个感知的概率分布。

1. 奖励是环境发出的一个信号。 它和观测一样，是从外部进到 agent 里的东西。agent 的目标被定义为"让环境发出尽量多的奖励"，而不是"完成奖励背后代表的那件事"。
2. agent 和环境是两个分开的东西。 环境能影响 agent 的唯一方式是给它输入，agent 影响环境的唯一方式是输出动作。环境没法改 agent 的代码，agent 也不会把"我自己"看成环境的一部分。

知道环境时的最优 agent：先要说清楚"拿尽量多的奖励"是什么意思。47 页的例子：
- agent 1 一上来就找到一个每步给 0.5 的办法，100 步后累计 50。
- agent 2 先花 90 步探索，平均每步 0.1，之后每步拿 1，100 步后累计 19。
- 但到 1000 步时，agent 2 是 919，agent 1 是 500。
谁更好取决于你多在乎远期奖励。所以要引入折扣：第 i 步的奖励乘上一个权重 γ_i（比如 α 的 i 次方，α 介于 0 和 1 之间）。α 越接近 1，agent 越有远见。48 页算出，α 大于约 0.991 时 agent 2 更优。这对应第 1 章那个"时间尺度"问题：折扣就是把"要多快学会"写成了一个参数。

它的决策规则展开，用文字说就是：  在当前这一步，对每个候选动作，想象所有可能的未来：环境会怎么回应（按 μ 给的概率取平均），我下一步会选最好的动作（取最大），环境再回应（取平均），我再选最好的（取最大）……一直推到无穷远，把沿途的折扣奖励加起来，选总值最大的那个当前动作。这就是 expectimax 搜索，也是 RL 里 Bellman 方程（49 页的式 2.1）的完整展开形式。区别只在于这里不假设 Markov 性，历史可以无限长。

AIXI：把未知的真实环境 μ，换成对所有可计算环境的混合 ξ。ξ = 对所有可计算环境 ν 求和，每个 ν 的权重是 2^(-K(ν))。然后把 2.9 节决策规则里的 μ 原封不动换成 ξ，就得到 AIXI，记作 π^ξ（52 页顶部的公式）。π^μ 是作弊：它事先知道环境。智能要求在不知道环境的情况下表现好。

用大白话说，AIXI 是这样决策的：  "我不知道自己在什么世界里。我把所有可能的世界都考虑进来，越简单的世界越可信。随着交互进行，用 Bayes 不断更新各个世界的可信度。每一步都在这个不确定性下做完整的 expectimax 规划。"

到这里，第 1 章定义的三个成分全都形式化了：交互（agent–环境模型）、目标（奖励）、未知的广泛环境（对所有可计算环境的混合）。但问题来了，主动设定比被动预测难得多。 52–56 页给了三个例子，层层递进：
1. 天堂与地狱（52–53 页）。  两扇门，一扇通往永远有奖励的天堂，另一扇通往永远没有奖励的地狱，进去就回不来。π^μ 知道哪扇是天堂。AIXI 不知道，只能猜。Legg 指出这不是 AIXI 的设计缺陷：如果把两扇门对调，原来的最优 agent 就会进地狱。没有任何一个 agent 能在两个环境里都最优。
2. Pareto 最优（53–54 页）。既然不能要求在每个环境都最优，退一步：定理 2.10.3 证明，没有任何别的 agent 能在所有环境中都至少和 AIXI 一样好、并且在某个环境中严格更好。Legg 自己也承认这个结果很弱：它不排除"所有通用 agent，包括 AIXI，表现都很差"。顺带一提，这篇论文之后，Leike & Hutter 2015 年进一步证明，这个最优性依赖于选哪台 universal Turing machine，换一台机器可以让 AIXI 表现任意差。
3. 大海捞针（55 页）。  N 个按钮里只有一个有奖励。描述"是哪个按钮"只需约 log2 N 个 bit，所以环境复杂度 K(μ) 很小。但任何不知道答案的 agent 都只能一个个试，平均要错 N 次，也就是 2^K(μ) 次。对比 Solomonoff 的预测误差上界是 K(μ) 量级。从被动预测到主动行动，最坏情况下学习代价从线性变成了指数。 这是整个 universal AI 理论的一个硬伤，Legg 在 55–56 页明确承认。

这一节本身没讨论 safety，但后来 safety 理论的几个核心问题，在这里都已经埋下了：
- 奖励是信号，不是意图 → wireheading / reward tampering。  
    AIXI 最大化的是"环境发出的奖励信号"。如果某个动作能直接改写这个信号（比如篡改奖励传感器），在 AIXI 的定义下这完全是一个合法的、而且很优的策略。Ring & Orseau 2011 就是在这个框架下证明 AIXI 类 agent 会这么做。这和今天 RL 训练中模型去改测试用例、直接攻击 grader 是同一个结构。
- 天堂与地狱 → 安全探索和不可逆性。  
    一个通用 agent 要学会环境，就必须尝试；但有些尝试的后果不可逆。理论上 AIXI 无法避免这一点。这就是后来 safe exploration 和"避免不可逆副作用"（low impact）这些问题的原型。
- agent 在环境之外 → embedded agency。  
    框架默认环境改不了 agent 的代码。所以 AIXI 无法正确思考"我被关机"或"我的权重被修改"这类事件，这也是 corrigibility 问题在这个框架里很难表述的原因。
- 被动 vs 主动的分界。  
    2.7 节被动预测有漂亮的保证，2.10 节一旦能行动，保证就大幅变弱，而且出现了"影响自己未来数据"的问题。这和我第一次提到的那个类比是对应的：pretraining 对应被动预测那一半，RL 训练才引入行动那一半，reward hacking 也主要在 RL 阶段出现。 这个对应仍然只是一个解释框架，不是证明：LLM 的 RL 训练和 AIXI 在细节上差很多，比如 LLM 的 episode 通常是独立重置的，没有天堂地狱式的不可逆。
